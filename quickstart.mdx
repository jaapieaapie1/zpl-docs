The ZPL renderer exposes a single HTTP endpoint at `https://caretly.dev/render`. Send your ZPL as the raw request body and the response is the rendered label.

## Get an API key

Every request needs an API key. Create one on the **API keys** page of the [console](https://caretly.dev/console). Start with a test key: it's free, and stamps **TEST** on every label. Then store the key in the `ZPL_API_KEY` environment variable:

```bash
export ZPL_API_KEY="zpl_test_..."
```

See [Authentication](/authentication) for live keys, billing and errors.

Click **Try it** to render the example shipping label directly from this page. Paste your key in the authorization field, and set `format` to `png` to preview the label inline.

## Example

```bash
curl -X POST "https://caretly.dev/render?format=pdf" \
  -H "Authorization: Bearer $ZPL_API_KEY" \
  -H "Content-Type: text/plain" \
  --data-binary @label.zpl \
  -o label.pdf
```

<Tip>
  Use `--data-binary` instead of `-d` so curl keeps the newlines in your ZPL intact.
</Tip>

<Note>
  Just trying ZPL? The [playground](https://caretly.dev/playground) renders in your browser without a key. It's free, but stamps **PREVIEW** on every label and PDF.
</Note>
