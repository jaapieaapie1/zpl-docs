The ZPL renderer exposes a single HTTP endpoint at `https://zpl.jaapelst.nl/render`. Send your ZPL as the raw request body and the response is the rendered label.

Click **Try it** to render the example shipping label directly from this page. Set `format` to `png` to preview the label inline.

## Example

```bash
curl -X POST "https://zpl.jaapelst.nl/render?format=pdf" \
  -H "Content-Type: text/plain" \
  --data-binary @label.zpl \
  -o label.pdf
```

<Tip>
  Use `--data-binary` instead of `-d` so curl keeps the newlines in your ZPL intact.
</Tip>
