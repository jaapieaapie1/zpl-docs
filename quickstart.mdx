This project comes with a very simple and tiny HTTP API, hosted on this domain [https://zpl.jaapelst.nl/render](https://zpl.jaapelst.nl/render).

## The render endpoint

### Query parameters

<ParamField query="format" default="pdf" type="string">
  The output format, can either be PNG or PDF
</ParamField>

<ParamField query="timings" type="string">
  Retrieve timings from the server in a header.
</ParamField>
